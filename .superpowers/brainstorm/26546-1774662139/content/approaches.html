A) Integrated Data-Viz

Every card has a gráfico embutido — area charts, donut charts, sparklines, progress bars. Os dados contam a história visualmente. Layout clean com bastante espaço. Patterns geométricos sutis no background. Cada seção se diferencia pelo TIPO de visualização (dashboard = area chart, yield = donut, FX = live grid, payments = flow diagram).

B) Hero Sections + Grafismos

Cada página abre com um hero section que tem ícone grande + título + subtítulo + grafismo geométrico abstrato decorativo. Cards têm gradient accent bars no topo que identificam a seção. Decorações SVG (círculos concêntricos, linhas diagonais) no background. Menos data-viz, mais identidade editorial. Cada page parece uma "capa" diferente.

C) Magazine Editorial + Data Dense

Números gigantes como headline editorial. Métricas em strip horizontal (tipo Bloomberg terminal moderno). Area chart + allocation bar combinados. Dot-grid pattern no fundo. Cada page tem uma "manchete" numérica diferente que comunica o dado mais importante em tamanho gigante. Combina density de dados com respiração — pouca decoração, os dados SÃO o grafismo.
